# Website
Visit the actual docs [here](linux.bwagner.dev).


All my knowledge of Linux, Docket, Git, and tech, simplfied on the internet.
Built using [Docusaurus](https://docusaurus.io/), turning Markdown in a modern React page.

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm build
```
